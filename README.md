# LEAP_project
This is a repository that contains the final project of the LEAP course for 'Machine Learning and applications'

**Project selected**: build a network that recognizes handwritten digits, then study where it makes its mistakes.

## Overview
The title of the project is "Where does your CNN make its mistakes?"

The aim of this project is to train an convolutional neural network to recognize handwritten digits. The outcome is not only a functional model but an evaluation of it and the study of its weaknesses to be able to understand what metrics matter the most and what we should consider before deploying a model for a real life application like a postal sorting center and a bank. 

## Structure of repository
`Final_Project_Option1_CNN_MNIST.ipynb`: the notebook with the outcomes of the project

`Report.pdf`: a summary of the model's performance, a study of the predictions and the weakness of the model and final conclusions
